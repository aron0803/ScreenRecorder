# 螢幕錄影工具使用手冊

歡迎使用螢幕錄影工具 (Screen Recorder)。本手冊將引導您如何使用此軟體進行螢幕錄製、錄音和截圖。

## 功能特色

- **高畫質錄影**：支援 MP4 格式錄製。
- **純音訊錄製**：支援 MP3 格式錄音。
- **聲音錄製**：自動錄製系統聲音及麥克風聲音。
- **快捷鍵支援**：
  - **F8**：開始 / 停止錄音
  - **F9**：開始 / 停止錄影
  - **F10**：螢幕截圖
- **自訂設定**：可調整 FPS、畫質及錄影範圍。
- **按鍵顯示**：可選擇是否顯示按鍵操作。
- **檔案分類管理**：自動將錄影、截圖、錄音分類儲存。

## 操作說明

### 1. 錄影設定
- **FPS (幀率)**：建議設定為 30 或 60。
- **畫質**：可選擇 低 / 中 / 高。
- **錄影範圍**：
  - **全螢幕**：錄製整個主螢幕。
  - **自訂範圍**：
    - 點擊「選取範圍」按鈕。
    - **拖曳滑鼠**：選擇要錄製的區域。
    - **單點視窗**：直接點擊某個視窗，即可自動選取該視窗範圍。
    - 選取後，螢幕上會出現**紅色框線**標示錄影範圍。
- **錄製聲音**：勾選「錄製聲音」以同時錄製系統與麥克風聲音。

### 2. 開始錄影
- 點擊 **「開始錄影」** 按鈕，或按下 **F9**。
- 程式視窗將會**自動縮小**至工作列，以免阻擋錄影畫面。
- 紅色框線將會消失，表示錄影開始。
- 狀態列將顯示「● 錄影中」及檔案名稱。

### 3. 開始錄音
- 按下 **F8** 開始純音訊錄製。
- 程式視窗將會**自動縮小**至工作列。
- 狀態列將顯示「● 錄音中」及檔案名稱。
- 同時錄製系統音訊和麥克風輸入。

### 4. 停止錄製/錄音
- 再次按下 **F9**（停止錄影）或 **F8**（停止錄音）。
- 或從工作列還原視窗後點擊「停止」按鈕。
- 程式視窗將會**自動還原**並顯示。
- 檔案將自動儲存於對應的資料夾中。

### 5. 截圖
- 按下 **F10** 即可快速截取當前畫面（或選定範圍）。
- 截圖會立即儲存，不影響正在進行的錄影/錄音。

### 6. 檔案管理
- 視窗下方列表顯示已錄製的影片、截圖和錄音。
- 雙擊項目即可開啟檔案。
- 右鍵點擊可刪除檔案。
- 點擊「開啟資料夾」按鈕可瀏覽所有錄製檔案。

## 檔案儲存位置

所有檔案都儲存在程式目錄下的 `record` 資料夾中，並自動分類：

- **錄影檔案**：`record/Videos/` (*.mp4)
- **截圖檔案**：`record/Screenshots/` (*.png)
- **錄音檔案**：`record/Audio/` (*.mp3)

## 按鍵顯示功能

- 勾選「顯示按鍵」可在錄影時顯示按鍵操作。
- 按鍵會顯示在錄影範圍的左下角。
- 支援組合鍵顯示（如 Ctrl + Alt + Del）。
- **注意**：如果按鍵顯示卡住（例如按 Ctrl+Alt+Del 後），點擊程式視窗即可自動清除。

## 長時間錄製說明

- 本程式使用串流寫入技術，錄製資料會即時寫入磁碟。
- 記憶體使用量不會隨錄製時間增長而持續增加。
- 正常情況下記憶體使用量約 100-200MB。
- 詳細資訊請參考 `MEMORY_MANAGEMENT.md`。

## 注意事項

- 錄影/錄音時請確保麥克風已連接並開啟，以確保收音正常。
- 錄影檔案較大時，儲存可能需要幾秒鐘，請耐心等待。
- 建議定期清理 `record` 資料夾以釋放磁碟空間。
- 如遇到按鍵顯示卡住，點擊程式視窗即可恢復正常。

## 快捷鍵總覽

| 快捷鍵 | 功能 | 說明 |
|--------|------|------|
| **F8** | 錄音 | 開始/停止純音訊錄製 |
| **F9** | 錄影 | 開始/停止螢幕錄影 |
| **F10** | 截圖 | 快速截取當前畫面 |
